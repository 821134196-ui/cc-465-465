# 保龄球馆 · 球道排队与球鞋消毒周转系统

纯 Node.js 内置模块实现（`node:http` + `node:sqlite` + `node:test`），**零第三方依赖**，Node ≥ 22.5 即可运行。

## 一条命令启动

```bash
node server.js --demo        # 演示模式：重置并写入高峰排队/换道/缺码样例数据
# 或
npm run demo                 # 同上
node server.js               # 普通模式：空库启动，仅基础档案
npm start
```

启动后访问 **http://localhost:8080/** （`--port 9090` 可改端口）。

```bash
npm test                     # 运行全部集成测试（8 项）
node seed.js --demo          # 仅重置演示数据，不启动服务
```

## 七个工作台

| 页签 | 功能 |
|---|---|
| 候场叫号 | 取号（人数/护栏/套餐）、叫下一位、过号标记与恢复、大组号+预计等待、现场事件流 |
| 球道平面图 | 8 条球道真实并列条带（木纹道面、蓝色箭头、白色瓶阵、护栏虚线），故障/计分器状态，报告/修复故障 |
| 开局控制 | 已叫号组 → 选球道 → 逐人选鞋码与球磅 → 开局锁道借鞋；进行中场次计时、结束结算、临时加人、卡球、计分器中断、还鞋 |
| 球鞋库存 | 34–46 码 × 鞋号矩阵，五色状态快速扫描，缺码红色预警 |
| 消毒队列 | 待消毒列表 → 一键开批 → 消毒完成回库；批次历史 |
| 故障换道 | 故障道受影响订单保留，前后球道同一水平线展示并一键换道；手动换道；换道/故障记录 |
| 结账复核 | 待结账（可填赔付/免单）、值班经理复核台、支付单与退款 |

右上角可切换 **前台A / 前台B**，用于演示双前台资源互斥。

## 业务规则实现要点

- **双锁**：开局/借鞋/换道均在 `BEGIN IMMEDIATE` 事务内用条件 `UPDATE ... WHERE status='idle'/'available'` 加 `changes` 校验——两个前台同时开同一球道或借同一双鞋，恰有一方成功，另一方收到 `409 LANE_BUSY / SIZE_SHORTAGE`。
- **球鞋周转**：归还即 `pending_disinfection`，开批消毒转 `disinfecting`，批次完成才回 `available`；全程不可借（消毒阻断）。
- **过号**：进程内任务（`src/tasks.js`，5 秒一拍）扫描叫号超时未开局的组自动记过号；恢复排队优先级 +1，再叫优先。
- **场次时长**：进程内任务为每个进行中场次维护已用时/预计用时快照，超预计在前端标红。
- **换道**：`lane_slots` 记录球道占用时段，目标道存在未结束时段即 `409 SLOT_BUSY`（换道不得占用已有时段）；故障道订单保留，修复前保持 `fault`。
- **计费**：按实际局数结算——未超局取「套餐价」与「门市价×局数」较低者；超局部分 ¥20/人/局，自动记 `extra_game` 事件。
- **赔付/免单**：结账含赔付或免单时支付单进入 `pending_review`，值班经理批准才入账，驳回则作废可重结。
- **幂等**：结账按 `idempotency_key` 去重（重复提交返回原单，不重复扣款）；退款按 `refund_key` 去重（并发重放只退一次）。
- **事件台账**：过号、临时加人、球鞋缺码、卡球、计分器中断、换道、超局、鞋件损坏等全部落 `events` 表并在前端事件流展示。
- **模拟适配器**：`src/adapters.js` 提供计分器（可模拟中断/恢复）与付款网关（按幂等键去重的 charge/refund），真实部署时替换即可。

## 数据与目录

```
data/bowling.db     SQLite（局次、借还、时段、支付、事件等全部记录）
data/photos/        鞋件损坏照片（还鞋时上传，前端事件流可查看）
```

## 演示样例（`--demo` 预置）

- **高峰排队**：10+ 组候场（含护栏需求组），5 条球道进行中，预计等待实时计算
- **故障换道**：3 号道摆瓶机卡瓶，受影响订单保留待换；5 号道计分器中断
- **球鞋缺码**：40 码全部租出，孙八（A011）开局即触发缺码事件；库存矩阵红色预警
- **消毒周转**：3 双待消毒 + 1 个进行中批次
- **结账复核**：1 笔待结账、1 笔已支付、1 笔赔付待经理复核

## 测试（`tests/system.test.js`，8 项全过）

双前台球道双锁 · 双前台球鞋双锁 · 过号自动标记与恢复优先 · 消毒阻断（待消毒/消毒中均不可借）· 故障换道时段冲突与超局计费 · 结账/退款幂等 · 赔付免单复核 · 临时加人与卡球事件
