# 星瓶保龄球馆 · 球道排队与球鞋消毒周转系统

一套本地运行的保龄球馆前台系统：候场叫号、按人数/护栏分配球道、开局锁定球道与球鞋、
设备故障换道、球鞋归还→待消毒→完成再借、按实际局数结账、值班经理复核赔付/免单/退款。
顾客与金额均为演示数据。仅使用 Python 3 标准库，无需安装依赖。

## 一条命令启动

```bash
cd bowling
python3 app.py
```

浏览器打开 <http://localhost:8000>（端口可用 `PORT=9000 python3 app.py` 修改）。
SQLite 数据库落在 `data/bowling.db`，球鞋损坏照片存在本地 `data/photos/`。
删除 `data/bowling.db` 即可恢复初始演示数据。

## 功能一览

| 模块 | 说明 |
|---|---|
| 候场叫号 | 候场屏突出组号、人数、护栏、所需鞋码与预计等待；叫号 5 分钟未确认由进程内定时任务自动过号，10 分钟内可「恢复队首」保留优先位置 |
| 球道平面图 | 两排**并列长条球道**（非卡片），木道浅棕、箭头蓝；空闲/进行中/故障/无护栏四种状态，故障道斜纹并暂停叫号 |
| 开局控制 | 开局原子锁定球道 + 逐双锁定球鞋；登记局数套餐、同步计分器局数、超局提示、卡球、计分器中断/恢复、换道、结束结账 |
| 球鞋库存 | 34–45 码**可快速扫描的圆点矩阵**，颜色区分在库/借出/待消毒/维修 |
| 消毒队列 | 球鞋归还即自动归集为待消毒批次；未消毒前该鞋阻断再借（表现为缺码），「消毒完成」后回库 |
| 故障换道 | 故障道暂停叫号并保留受影响订单；换道只在**同一水平排**点选，横幅显示「原道 ➜ 目标道」前后位置；目标道已有时段则拒绝 |
| 结账复核 | 按实际局数结算（套餐价 + 超局加收 + 鞋租）；免单/赔付/鞋损加收与退款均须值班经理工号复核；退款重复提交幂等 |

顶部可在 **前台1 / 前台2** 间切换，模拟两个前台并发操作。

### 异常事件均落库
过号、临时加人、球鞋缺码、卡球、计分器中断、换道、超局、鞋件损坏都会写入
`events` 表并显示在底部「异常事件记录」。

### 适配器（模拟）
- `ScorerAdapter`：返回计分器局数，可制造/恢复「计分器中断」，换道时局数跟随迁移。
- `PaymentAdapter`：返回付款状态；退款按 `payment_ref` 幂等，重复退款返回同一退款流水，只动一次账。

## 一键演示样例

候场叫号面板右上角：
- **高峰排队**：一次性涌入 8 个不同人数/护栏/鞋码的组，观察预计等待与球道适配。
- **球鞋缺码(45码)**：全场仅 1 双 45 码，两个 1 人组先后开局，第二组被「缺码」阻断；
  去进行中场次归还 45 码鞋 → 消毒队列「消毒完成」→ 第二组即可开局。
- **故障换道**：把一条进行中的球道置为故障（暂停叫号），在场次行点「换道」后，
  同一水平排选择空闲道；尝试换到已占用道会被拒绝。

## 主要操作路径

1. 取号入队（或用一键样例）→ **叫下一号**。
2. 已叫号组点「开局」→ 选局数套餐；球道与球鞋同时锁定，缺码则整单回滚。
3. 进行中：同步计分器局数（超过套餐局数记「超局」）、可登记卡球/计分器中断。
4. 球道故障：点故障道登记 → 场次行「换道」选同排空闲道。
5. 点球鞋编号标签归还：完好→待消毒批次；损坏→上传照片后进入维修。
6. 「消毒完成」球鞋回库可再借。
7. 「结束结账」生成账单 → 收款；需要免单/赔付时填经理工号复核；付款后可退款（幂等）。

## 测试

```bash
python3 -m unittest tests.test_system -v
```

覆盖 5 类关键场景（共 19 个用例）：
- **资源双锁**：两个前台不能同时开同一球道、借同一双鞋（属主级锁 + 并发线程竞争唯一赢家）。
- **过号恢复**：定时任务自动过号、恢复后保留队首优先位置、超出恢复时限被拒。
- **消毒阻断**：归还鞋在消毒完成前缺码阻断再借，消毒完成后恢复；损坏鞋进维修并存照片。
- **换道计费**：换到空闲道后旧时段关闭/新时段开启、占用道与故障道拒绝、超局按实际局数计费。
- **退款幂等**：重复退款返回同一流水、只记一次事件；退款/免单必须经理复核。

## 目录结构

```
bowling/
├── app.py                # 本地 HTTP 服务 + JSON API + 启动入口
├── bowling/
│   ├── db.py             # SQLite schema 与连接
│   ├── locks.py          # 时钟、属主级资源锁（球道/球鞋双锁）
│   ├── service.py        # 排队/开局/换道/消毒/结账领域逻辑
│   ├── adapters.py       # 模拟计分器与支付（退款幂等）
│   ├── scheduler.py      # 进程内定时任务（过号/场次时长）
│   ├── seed.py           # 演示数据
│   └── scenarios.py      # 高峰排队/缺码/换道一键样例
├── web/                  # index.html / styles.css / app.js
├── tests/test_system.py
└── data/                 # bowling.db 与 photos/（运行后生成）
```

## 设计要点
- 所有写操作在进程内 `svc_lock` 下完成 check-then-act，球道/球鞋另有属主级资源锁，
  SQLite 写锁作为纵深防御；时段占用用 `session_lanes` 的开区间表达，换道按区间重叠判定。
- 球鞋状态机：`in_stock → on_loan → sanitizing → in_stock`，损坏分支 `→ repair`。
- 配色：木道浅棕 `#c9a06a/#e7d3b4`、球道箭头蓝 `#1f6fb2`、瓶体白；球道按真实并列排面展示。
